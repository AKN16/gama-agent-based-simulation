# Agent-Based Simulation using GAMA

## Overview
This project implements an agent-based simulation using the GAMA platform. 
The simulation models interactions between different agents with behaviors such as movement, collision, and consumption.

## Features
- Random agent generation with different shapes and sizes
- Agent movement and interaction rules
- Collision and consumption mechanics
- Boundary interaction and agent splitting behavior

## Technologies
- GAMA Platform
- Agent-Based Modeling
- Simulation Design

## Purpose
This project explores how agent-based systems can simulate ecological interactions and emergent behaviors.
